# Validation・安全装置

## 3種類の検証

### 1. 構造検証

- JSON形式
- 必須項目
- 日本株・米国株の市場別項目
- 出典ID
- 日付・通貨・ティッカー
- update mode

### 2. 計算検証

- Bear＋Base＋Bullの確率が100%
- Bear < Base < Bull
- 確率加重期待値の再計算
- 期待リターンの再計算
- 株価変換
- 希薄化後株式数
- 転換社債のITM判定
- M&A三点セット
- 市場逆算の独立性
- TTMとフォワードの区別
- JPY／USDと単位

### 3. 掲載情報検証

- 共通7トピック
- 市場別必須情報
- 業種別追加情報
- カタリスト
- リスク
- 良い点・気になる点
- 用語
- 出典
- 未確認事項
- 前回レポートからの情報減少

### 4. 専用カタリスト検証

- 過去日程を今後一覧へ残していない
- 確定・会社目標・市場予想・当方推定・未確認を分離
- 重要度3以上に成功・想定内・失敗の3結果
- 株価影響レンジと分析基準株価の算術一致
- 織り込み度の根拠と反証
- 定量不能を架空の数値へ変換していない
- 同一材料の二重計上防止
- 資金調達、希薄化、材料出尽くし
- 先行指標と更新条件
- 重要度4〜5の一次情報
- シナリオページとの重大な論理矛盾

## FAIL条件

- 確率合計不一致
- シナリオ順序の不整合
- 期待値の計算不一致
- 重要数値の出典欠落
- 市場・通貨の不一致
- 参照先のないsourceRefs
- 危険なHTMLやJavaScript
- 売買断定
- 部分更新の変更範囲不一致
- 既存レポートから大幅な情報消失
- publishedなのに人の確認がない

## WARN条件

- 推定日程が多い
- 古い分析
- 出典数が少ない
- 用語・リスク・カタリストが少ない
- セクション数が減った
- 急騰・急落後
- アナリスト中央値とBaseが大幅乖離
- 未確認事項が残る

## 例外

銘柄特性により通常項目が存在しない場合は、無理に作りません。

例外には必ず次を残します。

- checkId
- 理由
- 承認者
- 承認日

AI自身を承認者にしません。

## 公開ゲート

1. draft JSON生成
2. 構造・計算・情報量検証
3. 非公開プレビュー生成
4. 既存ページとの比較
5. 人が表示と内容を確認
6. reviewへ変更
7. PR確認
8. publishedへ変更
9. 公開後のリンク・株価確認

専用カタリストはさらに、公開台帳が`published`で、人による確認者・確認日が記録されている場合だけ一覧ボタンを表示します。台帳の取得失敗時はボタンを出さないのが正常動作です。

## ロールバック

- report.jsonのrevisionを保持
- 生成HTMLを手修正しない
- 問題発生時は前revisionへ戻して再生成
- 株価データの障害時は分析基準値を表示
