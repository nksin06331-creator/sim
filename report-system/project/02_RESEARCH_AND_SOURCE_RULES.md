# 調査・出典ルール

## 共通

- 調査時点の最新情報を取得する。
- 重要数値は、会社公式資料・規制当局・取引所など一次情報を優先する。
- 現在株価、決算数値、株数、現金、負債には基準日を付ける。
- 推定値は「estimate」、モデル値は「assumption」と明記する。
- 出典が確認できない重要数値を事実として扱わない。
- 二次情報しかない場合は、二次情報であることと未確認事項を記載する。

## 米国株

優先順位：

1. SEC提出書類（10-K、10-Q、8-K、S-1、S-3、424B、DEF 14A等）
2. 企業IR・決算資料・決算説明会資料
3. 取引所・政府機関・規制当局
4. 信頼できる市場データ
5. 二次情報

必ず確認する項目：

- GAAP／Non-GAAPの区別
- Basic／Diluted shares
- SBC
- ATM、公募、私募
- 転換社債と転換価格
- Capped Call
- ワラント・オプション
- M&A対価
- CIK
- ADR、二重上場の有無

## 日本株

優先順位：

1. 企業IR・決算短信・有価証券報告書
2. TDnet・EDINET
3. 東京証券取引所・官公庁
4. 信頼できる市場データ
5. 二次情報

必ず確認する項目：

- 日本基準／IFRS／US-GAAP
- 証券コード
- 上場市場区分
- 決算月
- 発行済株式数と自己株式
- 株式分割・併合
- ストックオプション
- 増資・第三者割当
- 会社予想と市場予想の区別
- 配当、自社株買い
- 政策保有株

## カタリスト

各カタリストに次を記録します。

- 名称
- 時期
- 時期の確度
- 重要度
- 成功時に変わる前提
- 失敗・遅延時に崩れる前提
- 出典

時期は次のいずれかで表します。

- `confirmed`：正式日程
- `estimated`：過去傾向などからの推定
- `window`：会社が示した期間
- `unknown`：未発表

推定日を確定日として表示しません。

## 情報の鮮度

- 決算通過後は全面更新候補
- 基準株価から±20%以上動いた場合は再評価候補
- 45日を超えた分析は注意
- 120日を超えた分析は原則再調査
- 株式分割、増資、M&A、転換社債条件変更は即時全面再計算

  "accessedAt": "2026-07-31"
