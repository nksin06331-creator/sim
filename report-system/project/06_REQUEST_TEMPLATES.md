# ChatGPTへの依頼テンプレート

## 新規銘柄

```text
【新規作成】
対象：BE
更新モード：full-refresh

最新の一次情報を調査し、report.schema.json形式で
BE.report.jsonを作成してください。
日本株・米国株・業種別の必要項目を判定し、
固定項目に入らない重要情報はextraSectionsへ入れてください。
statusはdraftにしてください。
```

## 決算後の全面更新

```text
【全面更新】
対象：BE
更新モード：full-refresh

添付したBE.report.jsonを正本として、
最新決算、SEC、会社IR、株価、株数、現金、負債、
転換社債、カタリストを再調査してください。
前回から削除する情報がある場合は理由を更新履歴へ記録してください。
```

## カタリストだけ更新

```text
【部分更新】
対象：BE
更新モード：patch
変更対象：scenario.entryContext.catalysts

添付したBE.report.jsonを基準に、
カタリストだけを最新情報へ更新してください。
report-patch.schema.json形式で出力し、
指定していない項目は変更しないでください。
```

## 誤り訂正

```text
【訂正】
対象：BE
更新モード：correction
訂正対象：発行済株式数

正しい一次情報を確認し、計算への影響を判定してください。
計算へ影響する場合はpatchではなくfull-refreshが必要と明示してください。
```

## 専用カタリストレポートを新規作成

```text
【専用カタリストレポート】
対象：IONQ
更新モード：initial

最新の一次情報を調査し、catalyst-report.schema.json形式で
IONQ.catalyst.jsonを作成してください。
評価基準日から18か月を基本対象とし、
日程確度、成功・想定内・失敗、株価影響、織り込み度、
依存関係、材料出尽くし、希薄化、先行指標、更新条件を検証してください。
固定欄に入らない重要情報はextra_sectionsへ残してください。
HTMLは作成しないでください。
```

## 専用カタリストレポートを更新

```text
【専用カタリストレポート更新】
対象：IONQ
更新モード：full-refresh

添付したIONQ.catalyst.jsonを正本として、
最新の一次情報で全日程と結果条件を再検証してください。
過去日程は今後一覧から外し、変更理由をupdate_historyへ残してください。
確認できない日付や株価影響を創作しないでください。
```

## 日本株

```text
【日本株の新規作成】
対象：6857 アドバンテスト
更新モード：full-refresh

企業IR、決算短信、TDnet、EDINETを優先してください。
証券コード、市場区分、会計基準、決算月、
発行済株式、自己株式、株式分割、還元方針を確認してください。
report.schema.json形式、statusはdraftで出力してください。
```

## 表示確認

```text
【レビュー】
添付したreport.jsonについて、
数値計算、出典、情報不足、日本株・米国株の市場別項目、
業種固有情報、売買断定、古い情報を検証してください。
内容は変更せず、FAILとWARNの一覧だけを出してください。
```
