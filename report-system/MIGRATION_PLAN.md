# 段階移行計画

## Phase 0：現行保護

- 62銘柄×2ページの基準値を保存
- 現在のURLとライブ株価機能を固定
- 公開HTMLは変更しない

完了条件：

- BE、HOOD、6857でバイト一致
- 米国株・日本株の市場別検証PASS

## Phase 1：運用基盤

- JSONスキーマ
- 部分更新patch
- 計算Validation
- 情報量Validation
- HTML安全性検証
- 非公開プレビュー
- 任意の専用カタリストページ
- 専用カタリスト公開台帳
- 台帳障害時に既存2ボタンへ戻るフェイルセーフ

公開サイトへの影響：なし

## Phase 2：試験移行

候補：

- BE：米国株・転換社債・大型契約
- HOOD：米国金融・一時利益・規制
- 6857：日本株・IFRS・日本式会計年度

各銘柄をstructured JSONへ変換し、現行HTMLと比較します。

公開サイトへの影響：承認された銘柄だけ

## Phase 3：新規銘柄

新しいChatGPTプロジェクトからstructured JSONを出力します。

- HTMLはGitHub側で生成
- 新規銘柄は最初からdraft
- プレビューと人の確認後に公開

## Phase 4：既存銘柄の自然移行

決算更新や重要ニュースで触る銘柄だけ順次移行します。

一括変換しない理由：

- 銘柄特有情報の欠落を防ぐ
- 古いレポートの品質差を吸収する
- 業種別モジュールを実データで改善する

## Phase 5：自動化

十分な実績後に追加します。

- PR上の自動プレビュー
- 差分レポート
- 決算通過・20%変動・古さの警告
- 公開用ビルド
- ロールバック

自動公開は最後まで行いません。
