初心者向けに一言

この会社は決済会社だけではない。店舗が自社ブランドで発行する電子マネーやポイントの仕組み、店頭の電子看板、企業のメール配信をまとめて提供している。顧客の店舗運営と販促に深く入り込むため、継続利用が増えるほど収益が積み上がりやすい。

一方、預り金を含む現預金をすべて自由な余剰資金とみなすのは危険である。また、デジタルサイネージには機器販売と工事が含まれ、案件の納品時期によって売上と利益が前後する。

業績へつながる順番
  • 1利用拡大：独自Payの加盟店と利用者が増え、既存顧客1社あたりのオンラインチャージ利用が伸びる。
  • 2リカーリング売上：決済手数料やシステム利用料が毎月積み上がり、売上の質と利益率が改善する。
  • 3営業レバレッジ：固定費を上回る継続収益が増えれば、売上成長率以上に利益が伸びる余地がある。
  • 4案件変動：サイネージは大型案件、納品時期、機器構成で四半期ごとの利益率が変わる。

強みと弱み

強み：業務への組み込み

決済や店頭表示は店舗の日常運営に組み込まれるため、切り替えにはシステム移行と現場教育が必要になる。

強み：クロスセル

共通顧客へ独自Pay、デジタルギフト、サイネージ、メール配信を横断提案できる。

弱み：規模

時価総額と開発資源は大手決済・大手IT企業より小さく、大型投資や価格競争への耐性は限定的。

弱み：複合事業

リカーリングSaaSと機器・工事型ビジネスが混在し、単一倍率では評価しにくい。

重要用語
独自PayPrivate-label Pay⌄

定義：企業や店舗が自社ブランドで運営する電子マネー・ポイント基盤。
なぜ重要：顧客の囲い込みと購買データ活用につながる。
この銘柄では：バリューデザインがValue Cardなどを提供する。

MRRMonthly Recurring Revenue⌄

定義：毎月繰り返し発生する経常収益。
なぜ重要：単発売上より将来の収益を見通しやすい。
この銘柄では：2026年6月の前年同月比は103%、キャッシュレスのみ102%。

リカーリング売上Recurring Revenue⌄

定義：決済手数料やシステム利用料など継続的に発生する売上。
なぜ重要：利益率と業績安定性を左右する。
この銘柄では：キャッシュレス3Qのリカーリング売上は7.93億円、前年同期比+7.8%。

取扱高Gross Transaction Value⌄

定義：サービス上で処理された決済総額。会社の売上高とは異なる。
なぜ重要：決済手数料収入の母数になる。
この銘柄では：2026年6月は1,295億円、うちオンラインチャージ約37億円。

調整後EBITDAAdjusted EBITDA⌄

定義：営業利益に減価償却費と株式報酬費用などを足し戻した利益指標。
なぜ重要：事業の現金創出力を比較しやすい。
この銘柄では：FY2026会社予想は13.0億円、3Q進捗率81.2%。

デジタルサイネージDigital Signage⌄

定義：店頭や施設に設置するネットワーク接続型の電子看板。
なぜ重要：機器販売、設置、利用料、保守が売上になる。
この銘柄では：2026年6月末の累計設置面数は73,730面。

預り金Customer Deposits⌄

定義：顧客や利用者の資金など、会社が一時的に預かる負債。
なぜ重要：現預金から企業価値を計算するときに差し引いて見る必要がある。
この銘柄では：3Q末は16.37億円。月末が休日だった影響も含む。

EV/EBITDAEnterprise Value / EBITDA⌄

定義：企業価値をEBITDAで割る評価倍率。
なぜ重要：資本構成や減価償却の違いを調整して比較できる。
この銘柄では：本レポートでは預り金を除いた余剰現金を使い、3シナリオを試算する。

ガチ勢向けの深掘り

なぜPERではなくEV/EBITDAを主軸にしたか

2026年8月期の純利益予想3.60億円には税負担や一時項目の影響が出やすく、FY2027には移転補償金の特別利益が入る予定である。加えて、同社は買収で生じたのれんと減価償却を持つ。通常の事業収益力を比較するため、調整後EBITDAと企業価値を主軸にした。ただし調整後EBITDAは株式報酬費用を足し戻すため、株主にとって完全な現金利益ではない。

キャッシュレスの質

3Qのキャッシュレス売上は前年同期比+5.3%だが、セグメント利益は+19.9%。リカーリング売上拡大、利益率の低いスポット売上の構成比低下、コスト抑制が効いた。成長率だけでなく、売上構成が高収益側へ移るかが企業価値の中心になる。

月次KPIの注意点

取扱高1,295億円は会社売上ではなく、システム上で処理した決済総額である。累計ID数と店舗数も、そのまま課金ユーザー数や売上高を示さない。MRR前年比、リカーリング売上、セグメント利益率と組み合わせて判断する。

株主優待の扱い

300株以上で5,000円、500株以上で10,000円のデジタルギフトが予定されている。個人投資家には利回り効果がある一方、会社側には費用が発生するため、企業価値モデルでは優待価値を株価へ直接加算していない。
